# Сегодня - Task Management Application

Приложение для управления ежедневными задачами с отслеживанием времени.

## Функциональность

- Создание одной задачи на день
- Установка предполагаемого времени выполнения
- Отслеживание времени выполнения
- Возможность поставить на паузу
- Отметка о выполнении или сдаче
- История выполненных и сданных задач
- Фильтрация по датам

## Установка

1. Установите зависимости для сервера:
```bash
npm install
```

2. Установите зависимости для клиента:
```bash
cd client
npm install
```

## Запуск

1. Запустите сервер:
```bash
npm run dev
```

2. В отдельном терминале запустите клиент:
```bash
npm run client
```

Приложение будет доступно по адресу http://localhost:3000

## Технологии

- Frontend: React, Material-UI
- Backend: Node.js, Express
- Database: SQLite
